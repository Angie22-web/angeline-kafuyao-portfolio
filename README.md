# Angeline C. Kafuyao — Portfolio

A responsive personal portfolio featuring 44 published works in journalism, multimedia reporting, photography, and social media content.

## Publish with GitHub Pages

1. Upload these files to a public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`, then save.

The site uses plain HTML, CSS, and JavaScript, so it needs no build step.

## Update the portfolio

Edit the `projects` list near the top of `script.js`. Each entry follows:

```js
["Project title", "Category", "Organization", "https://project-link.com"]
```

Accepted categories are `News Article`, `News Report`, `Photos`, and `Reels`. New categories can be added by creating another filter button in `index.html`.
